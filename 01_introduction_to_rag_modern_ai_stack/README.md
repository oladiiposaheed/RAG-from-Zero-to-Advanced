# Module 1: Introduction to RAG and the Modern AI Stack

Welcome to Module 1 of the **RAG from Zero to Advanced** course.  
This module lays the foundation for building Retrieval-Augmented Generation (RAG) systems using **LangChain**, **LangGraph**, and **LangSmith**.

---

## What You Will Learn

- What RAG is and why it matters
- How RAG compares to fine-tuning and prompt engineering
- The core components of a RAG pipeline
- The roles of LangChain, LangGraph, and LangSmith
- How to set up a professional Python environment for the course
- The course projects you will build

---

---

## Prerequisites

Before starting this module, ensure you have:

- Python **3.9 or higher** installed
- Basic understanding of Python programming
- An OpenAI API key (or access to another LLM provider)
- A LangSmith account (free tier is sufficient)
